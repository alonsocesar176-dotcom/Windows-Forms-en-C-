Básicamente, hice esta calculadora en C# usando Windows Forms porque es una forma muy intuitiva de crear aplicaciones visuales en Windows. Lo primero que hice fue armar la pantalla en el diseñador visual: puse una caja de texto para que funcione como la pantalla y una serie de botones para los números del 0 al 9, las operaciones básicas como sumar o restar, y el botón de igual.

Por dentro, todo funciona reaccionando a lo que hace el usuario. Tengo un par de variables guardadas en la memoria del programa para recordar los datos. Cuando presionas un número, el código toma el texto de ese botón y lo va pegando en la pantalla. Cuando eliges una operación, por ejemplo la suma, el programa "guarda" en una variable el número que tenías escrito, se acuerda de que quieres sumar y limpia la pantalla para que pongas el siguiente valor. Al tocar el botón de igual, toma el nuevo número, hace la cuenta según la operación que habías elegido y te muestra el resultado final.

En cuanto a la clase del formulario, piensa en ella como la "receta" o la plantilla de toda la ventana. Es la encargada de unir la parte visual con la lógica del código; se encarga de dibujar los botones en la pantalla, de escuchar dónde hace clic la persona y de ejecutar las instrucciones matemáticas cada vez que se interactúa con la calculadora.
